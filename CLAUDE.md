## Project Overview

RiderMove is a repository of JetBrains Rider plugin samples and templates for plugin development.

## Tech Stack

- **Language**: Kotlin
- **Framework**: JetBrains Plugin SDK
- **Build**: Gradle

## Structure

- `samples/` - Example Rider plugins demonstrating various features:
  - Actions
  - CefToolWindow
  - CodeInspections
  - CodeVision
  - ContextActions
  - DataContext
  - InlayHints
  - Miscellaneous
  - Notifications
  - OptionPages
  - PostfixTemplates
  - QuickDocProvider
  - RdProtocol
  - SettingsProvider
- `template/` - Plugin template for creating new plugins

## Purpose

Educational resource and reference for Rider plugin development.
